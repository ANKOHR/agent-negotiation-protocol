# Lessons for KOML

Challenge IDs and explicit resolution references preserve objections across revisions. A new plan string alone should never erase an objection. Blocking objections take precedence over advisory ones.

Planted evidence validates deterministic rule execution and exact reconciliation. It does not validate the quality of an agent's reasoning or whether a declared resolution actually fixes an objection.

Operating rule: enumerate expectations independently, then corrupt an input and require computed output to change. Never substitute synthetic accuracy for real-use evidence.
